# Contributing

[简体中文](CONTRIBUTING.md) · [Home](README.en.md)

Use Issues to discuss bugs and features, or send a pull request. Include version, reproduction steps, expected/actual behavior and a small public dataset. Never upload keys, passwords, user databases or private records.

Branch from `main`. Use `feat / fix / docs / test / chore` commit prefixes and reference the Issue. Each commit should describe a coherent actual change, without fabricated history. Update both languages for new text and keep documentation aligned.

Add tests for behavior changes, run backend tests and frontend builds, and update the changelog. Contributions follow MIT; preserve third-party origins and licenses. See the [development guide](docs/development.en.md). Tag accepted versions, then publish Release drafts after package verification.
