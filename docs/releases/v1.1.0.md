# 知数 Zhishu v1.1.0

新增数据源业务上下文：业务说明、字段解释、指标定义和关联关系。用户确认后保存，AI 规划、修正和总结使用同一个版本快照，历史与导出可回看依据。新增 20 对中英文业务标准答案案例及独立真实模型评测。修复组合筛选中的逻辑运算符校验问题。

Business context adds source notes, column descriptions, metric definitions and relationships. Save user-confirmed definitions; planning, repairs and summaries use one versioned snapshot, retained in history and exports. Includes 20 paired Chinese/English golden cases and a separate live-model evaluation runner. Fixes logical-operator validation in compound filters.

升级 / Upgrade: 退出旧版并备份整个存储目录，完整解压新版后启动；首版数据和设置可以继续使用。Quit the old version, back up the complete storage folder, extract the new archive and launch. v1.0 data and settings remain usable.

限制 / Scope: 业务知识辅助查询，不是完整语义引擎；规则模式不采用业务定义；不支持跨数据源查询；模型结果仍需核对。Context assists querying, not a full semantic engine. Demo mode does not apply definitions; no cross-source queries; verify model outputs.
