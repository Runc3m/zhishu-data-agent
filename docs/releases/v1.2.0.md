# 知数 InsightBridge v1.2.0

用业务语言提问，得到有依据的分析。Ask a business question. Get an analysis you can check.

## 简体中文

- **对话式 BI**：问“哪个卖得最好”，继续问“解释一下”或“我该关注什么”；保留多查询证据，输出发现、建议与局限。
- **12 种图形与指标视图**：支持数据兼容性选择、多系列趋势、图片和逐面板 CSV 导出。
- **真实数据与排查**：多 CSV ZIP、Olist 13 表仓库、表级血缘、ETL/加载记录与独立核验。Olist 数据单独下载。
- **业务依据与聊天管理**：关键词检索、上下文版本、证据导出；支持删除单个会话。
- **双语体验**：默认简体中文，可切换 English；更新中英文首页和指南。

下载 `Zhishu-v1.2.0-windows-x64.zip`，完整解压，双击 `Zhishu.exe`。无需安装 Python 或 Node.js。无需 Key 可体验规则演示；AI 自由问答需配置自己的模型服务。

升级：先退出旧版并备份 `%LOCALAPPDATA%\ZhishuDataAgent\storage`（包括 `local.key`），再解压启动新版。不要删除或覆盖存储目录。

Windows 包内置关键词检索，不含语义向量模型；源码版可选安装 FastEmbed / ONNX。应用为本地单用户工具，尚未代码签名。远程 AI 会接收必要上下文并可能产生 API 费用。

## English

- **Conversational BI:** ask “Which sells best?”, then “Explain this” or “What should I look into?” Multi-query evidence supports findings, conditional suggestions, and limitations.
- **12 chart/KPI views:** compatible view selection, grouped trends, image and per-panel CSV export.
- **Real data and investigations:** multi-CSV ZIP, a 13-table Olist warehouse, table lineage, ETL/load records and independent checks. Download Olist separately.
- **Business evidence and chat management:** keyword retrieval, context versions, evidence exports, and individual conversation deletion.
- **Bilingual experience:** Simplified Chinese by default, switchable to English; refreshed guides and project pages.

Download `Zhishu-v1.2.0-windows-x64.zip`, extract everything, and open `Zhishu.exe`. No Python or Node.js required. Rule-based demos need no key; free-form AI requires your model configuration.

Before upgrading, quit the old version and back up `%LOCALAPPDATA%\ZhishuDataAgent\storage`, including `local.key`. Extract and launch the new package without replacing your storage.

Windows includes keyword retrieval, without semantic model files. FastEmbed / ONNX is optional in the source edition. This is a local single-user application and is not code-signed. Remote AI receives necessary context and may incur API charges.
