First public release: Chinese/English switching, natural-language read-only analysis, charts and SQL, CSV / database sources, history and exports, and a Windows launch center.

Extract the entire ZIP and double-click `Zhishu.exe`; no Python / Node.js required. Demo mode is the default. DeepSeek AI needs only your own key. The app is unsigned; use the included SHA-256 checksum to verify downloads. Existing users should quit and back up the entire storage folder before updating.

限制 / Limitations: 本地单用户，尚不支持 Excel 或跨数据源关联；模型结果需核对。Local single-user use; no Excel or cross-source joins yet; verify model outputs.
