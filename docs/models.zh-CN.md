# 模型配置

[English](models.en.md) · [首页](../README.md)

## DeepSeek

在“模型设置”选择“AI 分析”，保持 DeepSeek，填写自己的 API Key，点击“验证并启用”。官方接口和模型由预设提供，无需填网址和名称。连接测试只验证服务可调用，不代表每个分析都正确。

Key 加密保存在本机，日后留空继续使用已保存值。切换提供商或自定义地址时需要对应 Key，不会把旧 Key 自动发往新地址。规则模式可明确勾选清除已保存 Key。

## 其他服务与本地模型

选择“其他兼容服务 / 本地模型”，填写根地址和准确模型名称。需兼容 `/chat/completions`；例如本地 Ollama 根地址为 `http://localhost:11434/v1`，名称与已安装模型一致。远程地址使用 HTTPS，无鉴权的本地模型可留空 Key。兼容协议不保证每个模型都能稳定生成计划。

## 数据流与回答

规划时发送问题、表结构、最近最多 10 条消息；总结时发送 SQL、列名和最多 30 行结果。数据库凭据与本机文件路径不作为模型上下文。请按数据所属组织规定选择服务。

默认按界面语言回答，问题中可明确要求其他语言。本次分析使用开始时的语言。模型输出可能出错，业务使用前应核对 SQL 与数据。API 费用由服务商收取；规则模式不调用模型。
